# Decisão da Comissão, de 30/10/2008 relativa à compatibilidade com o mercado comum de uma operação de concentração (Processo no COMP/M.5328 - GOLDMAN SACHS / APPLIANCES COMPONENTS COMPANY / BIANCHI VENDING / FINDER) com base no Regulamento (CE) n. 139/2004 do Conselho (Apenas faz fé o texto em língua inglesa)

**Texto:** versão original publicada no Jornal Oficial (sem alterações posteriores, se as houver).

## Texto

| 25.11.2008 | PT | Jornal Oficial da União Europeia | C 302/1 |
|---|---|---|---|

**Não oposição a uma concentração notificada**

**(Processo COMP/M.5328 — Goldman Sachs/Appliances Components Company/Bianchi Vending/Finder)**

**(Texto relevante para efeitos do EEE)**

(2008/C 302/01)

A Comissão decidiu, em 30 de Outubro de 2008, não se opor à concentração acima referida, declarando-a compatível com o mercado comum. Esta decisão tem por base o n.º 1, alínea b), do artigo 6.º do Regulamento (CE) n.º 139/2004 do Conselho. O texto integral da decisão é acessível apenas em inglês e a mesma será tornada pública logo que sejam retirados eventuais segredos comerciais. Pode ser consultada:

- — no sítio Web da DG Concorrência no servidor Europa (http://ec.europa.eu/comm/competition/mergers/cases/). Este sítio Web inclui diversos mecanismos de pesquisa das decisões de concentrações, nomeadamente por empresa, número do processo, data e índices sectoriais,

- — em formato electrónico na base de dados EUR-Lex, procurando pelo número de documento 32008M5328. EUR-Lex é o sistema informatizado de documentação jurídica comunitária (http://eur-lex.europa.eu).
