# 1999/799/CE: Decisão da Comissão, de 29 de Outubro de 1999, que estabelece o programa comunitário de quadros estatísticos a armazenar no banco de dados tabulares (BDT) do sistema Eurofarm [notificada com o número C(1999) 3455]

**Texto:** versão original publicada no Jornal Oficial (sem alterações posteriores, se as houver).

## Preâmbulo

A COMISSÃO DAS COMUNIDADES EUROPEIAS,

Tendo em conta o Tratado que institui a Comunidade Europeia,

Tendo em conta o Regulamento (CEE) n.º 571/88 do Conselho, de 29 de Fevereiro de 1988, relativo à organização de uma série de inquéritos comunitários sobre a estrutura das explorações agrícolas(1), com a última redacção que lhe foi dada pela Decisão 98/377/CE da Comissão(2), e nomeadamento, o segundo travessão do ponto 2 do seu anexo II,

Considerando que:

(1) Pela Decisão 97/341/CE(3), a Comissão estabeleceu o programa comunitário de quadros estatísticos a serem armazenados no banco de dados tabulares (BDT) do sistema Eurofarm; que a Decisão 98/377/CE estabeleceu alterações importantes à lista de características a inquirir no que respeita aos inquéritos estruturais comunitários exaustivos a realizar no período 1999/2000; que é, pois, necessário estabelecer um novo programa comunitário de quadros para o banco de dados tabulares (BDT);

(2) O programa de quadros deve respeitar o ponto 13 do anexo II do Regulamento (CEE) n.º 571/88, que diz que os quadros incluídos no BDT não devem permitir nenhuma identificação directa ou indirecta das explorações;

(3) O programa de quadros tem de levar em conta as crescentes necessidades dos utilizadores no que respeita a dados que reflictam melhor as suas necessidades de informação;

(4) Os quadros para os diversos níveis de agregação devem ser concebidos de forma a levar em conta a fiabilidade estatística dos resultados dos inquéritos;

(5) No âmbito da reforma da política agrícola comum, são necessárias longas séries de dados comparáveis para se poder acompanhar a tendência do desenvolvimento da estrutura das explorações agrícolas; que tais dados devem ser de acesso fácil e rápido para o utilizador. É por conseguinte necessário que os resultados dos inquéritos sobre a estrutura das explorações agrícolas comunitárias, efectuados no período de 1988 a 1997, se encontrem igualmente disponíveis no formato do novo programa de quadros para o banco de dados tabulares (BDT);

(6) As medidas previstas na presente decisão estão de acordo com o parecer do Comité Permanente das Estatísticas Agrícolas,

ADOPTOU A PRESENTE DECISÃO:

## Texto

### Artigo 1.º

1. Para os inquéritos exaustivos à estrutura agrícola no período 1999/2000, o programa comunitário de quadros para o banco de dados tabulares (BDT) do sistema Eurofarm, conforme previsto no anexo II do Regulamento (CEE) n.º 571/88, será de acordo com o estabelecido no anexo da presente decisão.

2. A fim de disponibilizar longas séries de dados comparáveis, o novo programa de quadros acima referido será aplicado igualmente aos dados que foram recolhidos no âmbito dos inquéritos sobre a estrutura das explorações agrícolas efectuados em 1989/1990, 1993, 1995 e 1997. Esses quadros suplementares para os inquéritos precedentes constituem um elemento integral do novo programa de quadros e serão igualmente incluídos no banco de dados tabulares (BDT) do sistema Eurofarm.

### Artigo 2.º

1. A informação estatística armazenada no banco de dados tabulares (BDT) não estará acessível aos utilizadores antes de o Serviço de Estatística das Comunidades Europeias, em colaboração com os Estados-Membros, ter estabelecido que a mesma cumpre os critérios e regras que regem a confidencialidade e a fiabilidade estatísticas a estabelecer conjuntamente com os Estados-Membros.

2. Os quadros mencionados no artigo 1.º e os quadros ad hoc definidos no ponto 15 do anexo II do Regulamento (CEE) n.º 571/88 serão inicialmente armazenados num quadro especial do banco de dados tabulares (BDT), ao qual apenas poderão aceder o Serviço de Estatística das Comunidades Europeias e os serviços estatísticos dos Estados-Membros, no que respeita aos quadros relativos ao respectivo país.

3. Os quadros ad hoc para os quais os serviços competentes dos Estados-Membros tenham assegurado a confidencialidade e a fiabilidade estatística podem também ser introduzidos no banco de dados tabulares (BDT), se forem de interesse geral.

### Artigo 3.º

Os Estados-Membros são os destinatários da presente decisão.

Feito em Bruxelas, em 29 de Outubro de 1999.

Pela Comissão

Pedro SOLBES MIRA

Membro da Comissão
