# TRATADO QUE INSTITUI A COMUNIDADE EUROPEIA — PARTE I: OS PRINCIPIOS — ARTIGO 1

**Texto:** versão original publicada no Jornal Oficial (sem alterações posteriores, se as houver).

## Texto

### Artigo 1.º

Pelo presente Tratado, as Altas Partes Contratantes instituem entre si uma Comunidade Europeia.
