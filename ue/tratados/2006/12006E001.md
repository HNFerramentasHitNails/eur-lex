# Tratado que institui a Comunidade Europeia (Versão consolidada) — Parte I - Os princípios — Artigo 1.°

**Texto:** versão original publicada no Jornal Oficial (sem alterações posteriores, se as houver).

## Texto

### Artigo 1.º

Pelo presente Tratado, as ALTAS PARTES CONTRATANTES instituem entre si uma COMUNIDADE EUROPEIA.
