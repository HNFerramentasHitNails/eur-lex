#### 1. Âmbito de aplicação

O presente regulamento abrange os sistemas silenciosos de escape de substituição para veículos das categorias M1 e N1. [^1]

#### 2. Definições

Para efeitos do presente regulamento, entende-se por:

|  | 2.1. | «Sistema silencioso», um conjunto completo de componentes necessários para limitar o som produzido pelo motor de um veículo, pela sua admissão e pelo seu escape; |
|---|---|---|

|  | 2.2. | «Sistema silencioso», um conjunto completo de componentes necessários para atenuar o ruído provocado pelo motor de um veículo a motor e respetivo escape; |
|---|---|---|

|  | 2.3. | «Sistema silencioso de escape ou componente de um sistema silencioso de escape com geometria variável», um sistema silencioso de escape ou componente de um sistema silencioso de escape com uma ou mais peças ou dispositivos móveis que, através da alteração da geometria do sistema silencioso ou do componente de um sistema silencioso de escape, podem modificar o seu desempenho em matéria de redução das emissões sonoras [por exemplo, peças móveis ou dispositivos que alterem o desempenho de redução do ruído através da abertura ou do fecho de uma ou mais válvulas do caudal dos gases de escape em função da variação das condições de condução ou do motor (rpm, carga, velocidade, etc.)]; |
|---|---|---|

|  | 2.4. | «Componente de um sistema silencioso de escape», cada um dos componentes isolados cujo conjunto forma o sistema silencioso de escape (por exemplo, o silencioso propriamente dito, a câmara de expansão, o ressonador); |
|---|---|---|

|  | 2.5. | «Sistemas silenciosos de escape de tipos diferentes» designa os sistemas silenciosos de escape que diferem significativamente no que respeita a, pelo menos, um dos seguintes elementos: |
|---|---|---|

|  | 2.5.1. | Designações comerciais ou marcas dos componentes; |
|---|---|---|

|  | 2.5.2. | Características dos materiais que constituem os seus componentes, exceto no caso do revestimento dos componentes; |
|---|---|---|

|  | 2.5.3. | Forma ou dimensão dos componentes; |
|---|---|---|

|  | 2.5.4. | Princípios de funcionamento de pelo menos um dos componentes; |
|---|---|---|

|  | 2.5.5. | Montagem dos componentes; |
|---|---|---|

|  | 2.5.6. | Número de sistemas silenciosos de escape ou de componentes; |
|---|---|---|

|  | 2.6. | «Sistema silencioso de escape de substituição ou seus componentes», qualquer elemento do sistema silencioso de escape definido no ponto 2.2 anterior destinado a ser utilizado num veículo que não seja um elemento do tipo montado no referido veículo aquando da sua apresentação para homologação nos termos do presente regulamento; |
|---|---|---|

|  | 2.7. | «Família de sistemas silenciosos de escape de substituição ou seus componentes», os sistemas silenciosos de escape ou os seus componentes para os quais todas as características previstas no ponto 6.4.1 são as mesmas; |
|---|---|---|

|  | 2.8. | «Homologação de um sistema silencioso de escape de substituição ou seus componentes», a homologação de parte ou de todo o sistema silencioso de escape adaptável a um ou mais modelos específicos de veículos a motor no que diz respeito à limitação do respetivo nível de ruído; |
|---|---|---|

|  | 2.9. | «Modelo de veículo», uma categoria de veículos a motor que não diferem entre si quanto a aspetos essenciais como: |
|---|---|---|

|  | 2.9.1. | O tipo de motor (ignição comandada ou por compressão, a dois ou quatro tempos, de êmbolos alternativos ou rotativos), o número e volume dos cilindros, o número e tipo de carburadores ou de sistemas de injeção, a disposição das válvulas, ou o tipo de motor elétrico; |
|---|---|---|

|  | 2.9.2. | «Potência útil nominal máxima», Pn, a potência do motor expressa em kW e medida pelo método da UNECE, nos termos do Regulamento n.º 85 da ONU. No entanto, se a potência útil nominal máxima e a velocidade do motor correspondente diferirem apenas em virtude de diferenças de mapeamento do motor, esses veículos podem ser considerados como veículos do mesmo modelo; |
|---|---|---|

|  | 2.9.3. | O sistema silencioso. |
|---|---|---|

#### 3. Pedido de homologação

|  | 3.1. | O pedido de homologação de um sistema silencioso de escape de substituição ou seus componentes deve ser apresentado pelo fabricante ou pelo seu representante devidamente acreditado. |
|---|---|---|

|  | 3.2. | Deve ser acompanhado dos documentos adiante mencionados, em triplicado, e das seguintes indicações: |
|---|---|---|

|  | 3.2.1. | Uma descrição do(s) modelo(s) de veículo a que o sistema de escape ou os componentes se destinam, no que diz respeito aos aspetos enumerados no ponto 2.7 anterior. Os números e/ou os símbolos que identifiquem o tipo de motor e o modelo do veículo devem ser indicados, tal como o número de homologação do modelo de veículo, se for necessário; |
|---|---|---|

|  | 3.2.2. | Uma descrição do sistema silencioso de escape montado, com indicação da posição relativa de cada um dos componentes, bem como instruções de montagem; |
|---|---|---|

|  | 3.2.3. | Desenhos de pormenor de cada componente do silencioso de escape, de modo a permitir a sua fácil localização e identificação, assim como indicação dos materiais utilizados. |
|---|---|---|

|  | 3.2.4. | Uma ficha de informações elaborada em conformidade com o apêndice do anexo 1. |
|---|---|---|

|  | 3.3. | A pedido do serviço técnico responsável pela realização dos ensaios de homologação, o fabricante do sistema silencioso de escape deve apresentar: |
|---|---|---|

|  | 3.3.1. | Uma amostra do sistema silencioso de escape ou dos componentes silenciosos de escape apresentados para homologação; |
|---|---|---|

|  | 3.3.2. | Uma amostra do sistema silencioso de escape de origem que equipava o veículo aquando da apresentação para homologação; |
|---|---|---|

|  | 3.3.3. | Um veículo representativo do modelo a equipar; para ser aceitável, este veículo deve cumprir os requisitos do ponto 8.1 do Regulamento n.º 51 da ONU (conformidade da produção). Para efeitos da aplicação do ponto 8.1, a referência ao ponto 6 diz respeito apenas aos pontos 6.1 e 6.2. |
|---|---|---|

|  | 3.3.4. | Um motor separado e componentes correspondentes, no mínimo, à cilindrada e à potência útil nominal máxima do veículo anteriormente mencionado, quando aplicável. O motor deve estar equipado com os meios necessários à realização dos ensaios especificados nos pontos 6.3.4.1 e/ou 6.4.3. |
|---|---|---|

|  | 3.3.5. | A cada tipo de sistema silencioso de substituição ou seus componentes homologados enquanto unidades técnicas deve ser atribuído um número de homologação; a secção 3 do número de homologação deve indicar o número do presente regulamento. Além disso, se o sistema silencioso de substituição se destinar a ser montado em modelos de veículos que cumpram os valores-limite da Fase 1, conforme indicado no ponto 6.2.2 da série 03 de alterações do Regulamento n.º 51 da ONU, o número de homologação deve ser seguido da letra «A». Se o sistema silencioso de substituição se destinar a ser montado em modelos de veículos que cumpram os valores-limite da Fase 2, conforme indicado no ponto 6.2.2 da série 03 de alterações do Regulamento n.º 51 da ONU, o número de homologação deve ser seguido da letra «B». Se o sistema silencioso de substituição se destinar a ser montado em modelos de veículos que cumpram os valores-limite da Fase 3, conforme indicado no ponto 6.2.2 da série 03 de alterações do Regulamento n.º 51 da ONU, o número de homologação deve ser seguido da letra «C». A mesma parte contratante não pode atribuir o mesmo número a outro tipo de sistema silencioso de substituição ou seus componentes. |
|---|---|---|

#### 4. Marcações

|  | 4.1. | Cada componente do sistema silencioso de escape de substituição, com exceção dos tubos e acessórios de montagem, deve ostentar: |
|---|---|---|

|  | 4.1.1. | a marca ou nome do fabricante do sistema ou dos seus componentes, |
|---|---|---|

|  | 4.1.2. | a designação comercial dada pelo fabricante. |
|---|---|---|

|  | 4.2. | A marcação deve também incluir a letra «A», se o sistema silencioso de substituição se destinar a ser montado em modelos de veículos que cumpram os valores-limite da Fase 1, conforme indicado no ponto 6.2.2 da série 03 de alterações do Regulamento n.º 51 da ONU; a letra «B», se o sistema silencioso de substituição se destinar a ser montado em modelos de veículos que cumpram os valores-limite da Fase 2, conforme indicado no ponto 6.2.2 da série 03 de alterações do Regulamento n.º 51 da ONU, ou a letra «C», se o sistema silencioso de substituição se destinar a ser montado em modelos de veículos que cumpram os valores-limite da Fase 3, conforme indicado no ponto 6.2.2 da série 03 de alterações do Regulamento n.º 51 da ONU. Ver no anexo 2 um exemplo da disposição da marca de homologação. |
|---|---|---|

|  | 4.3. | Estas marcas devem ser nitidamente legíveis e indeléveis. |
|---|---|---|

#### 5. Homologação

|  | 5.1. | Se o tipo de sistema silencioso de escape de substituição apresentado para homologação nos termos do presente regulamento cumprir os requisitos do ponto 6 seguinte, a homologação é concedida para esse tipo. |
|---|---|---|

|  | 5.2. | A cada modelo homologado é atribuído um número de homologação. Os dois primeiros algarismos (atualmente 03, correspondendo à série 03 de alterações ao presente regulamento) indicam a série de alterações que incorpora as principais e mais recentes alterações técnicas ao regulamento na data da emissão da homologação. A mesma parte contratante não pode atribuir o mesmo número a outro tipo de sistema silencioso de substituição ou componente destinado ao(s) mesmo(s) modelo(s) de veículo. |
|---|---|---|

|  | 5.3. | A homologação ou a recusa da homologação de um sistema silencioso de escape de substituição ou dos seus componentes nos termos do presente regulamento deve ser comunicada às partes no Acordo que apliquem o presente regulamento através do envio de um formulário conforme com o modelo do anexo 1 do presente regulamento e de desenhos do sistema silencioso de escape ou dos componentes, fornecidos pelo requerente da homologação, num formato que não exceda o formato A4 (210 × 297 mm) ou dobrados nesse formato e a uma escala adequada. |
|---|---|---|

|  | 5.4. | Em todos os componentes do sistema silencioso de escape conformes com um tipo homologado nos termos do presente regulamento deve ser afixada uma marca de homologação internacional composta por: |
|---|---|---|

|  | 5.4.1. | um círculo envolvendo a letra «E», seguida do número distintivo do país que concedeu a homologação [^2]; |
|---|---|---|

|  | 5.4.2. | o número do presente regulamento, seguido da letra «R», um travessão e o número de homologação, à direita do círculo previsto no ponto 5.4.1. |
|---|---|---|

|  | 5.4.3. | o número de homologação constante do certificado de homologação e o método usado para os ensaios de homologação. |
|---|---|---|

|  | 5.5. | A marca de homologação deve ser indelével e facilmente legível quando o sistema silencioso de escape estiver instalado no veículo. |
|---|---|---|

|  | 5.6. | Um componente pode ostentar vários números de homologação caso tenha sido homologado como componente de vários sistemas silenciosos de escape de substituição; neste caso, o círculo não precisa de ser repetido. O anexo 2 do presente regulamento apresenta um exemplo de disposição da marca de homologação. |
|---|---|---|

#### 6. Especificações

|  | 6.1. | Especificações gerais |
|---|---|---|

|  | 6.1.1. | O sistema silencioso de escape de substituição ou seus componentes devem ser concebidos, construídos e estar aptos a ser montados de tal modo que, nas condições normais de utilização e apesar das vibrações às quais possam estar sujeitos, os veículos cumpram o disposto no presente regulamento. |
|---|---|---|

|  | 6.1.2. | O sistema silencioso de escape ou os seus componentes devem ser concebidos, construídos e estar aptos a ser montados de tal modo que apresentem, face a fenómenos de corrosão aos quais estejam sujeitos, uma resistência razoável tendo em conta as condições de utilização do veículo, incluindo as diferenças climáticas regionais. |
|---|---|---|

|  | 6.1.3. | Prescrições adicionais relacionadas com a violabilidade e sistemas silenciosos de escape com modos de funcionamento múltiplos de regulação manual. |
|---|---|---|

|  | 6.1.3.1. | Todos os sistemas silenciosos de escape devem ser construídos por forma que não seja possível remover facilmente defletores, cones de saída e outras peças que funcionem principalmente enquanto elementos das câmaras de expansão/de silenciosos de escape. Caso seja inevitável integrar uma peça desta natureza, o seu método de fixação não deve facilitar a remoção (por exemplo, com fixações roscadas convencionais), devendo a fixação ser feita de modo que a remoção provoque danos permanentes/irremediáveis no conjunto. |
|---|---|---|

|  | 6.1.3.2. | Os sistemas silenciosos de escape com modos de funcionamento múltiplos de regulação manual devem cumprir todos os requisitos em todos os modos de funcionamento. Os níveis sonoros declarados são os que resultam do modo que apresente os níveis sonoros mais elevados. |
|---|---|---|

|  | 6.2. | Especificações relativas aos níveis sonoros |
|---|---|---|

|  | 6.2.1. | Condições de medição |
|---|---|---|

|  | 6.2.1.1. | O ensaio de emissões sonoras do sistema silencioso e do sistema silencioso de escape de substituição tem de ser executado com os mesmos pneus «normais» (tal como definidos no ponto 2 do Regulamento n.º 117 da ONU). Os ensaios não podem ser feitos com pneus para «utilização especial», nem de «neve» na aceção do ponto 2 do Regulamento n.º 117 da ONU. Estes pneus poderiam aumentar o nível sonoro do veículo ou ter um efeito de máscara na comparação do desempenho em matéria de redução das emissões sonoras. Os pneus podem já ter sido utilizados, mas devem cumprir as prescrições legais de utilização em circulação. |
|---|---|---|

|  | 6.2.2. | O desempenho em matéria de redução das emissões sonoras do sistema silencioso de escape de substituição ou dos seus componentes deve ser verificado através dos métodos descritos nos pontos 6.2.1, 6.2.2 e 6.2.3 do Regulamento n.º 51. Em especial, para efeitos da aplicação do presente ponto, deve ser feita referência à série de alterações ao Regulamento n.º 51 da ONU que se encontrava em vigor aquando da homologação do veículo novo. <br> a) Medição com o veículo em marcha Ao montar o sistema silencioso de escape de substituição ou os seus componentes no veículo mencionado no ponto 3.3.3, os níveis sonoros obtidos devem satisfazer uma das seguintes condições: i) O valor medido (arredondado ao número inteiro mais próximo) não deve ultrapassar em mais de 1 dB(A) o valor de homologação obtido nos termos do Regulamento n.º 51 da ONU com o modelo de veículo em questão; ii) O valor medido (antes de qualquer de arredondamento ao número inteiro mais próximo) não deve ultrapassar em mais de 1 dB(A) o valor sonoro medido (antes de qualquer de arredondamento ao número inteiro mais próximo) no veículo referido no ponto 3.3.3, se este estiver equipado com um sistema silencioso do tipo que estava montado no veículo aquando da sua apresentação para homologação nos termos do Regulamento n.º 51 da ONU. Se, para efeitos da aplicação do ponto 3.1.2.1.4.2 e/ou do ponto 3.1.2.2.1.2 do anexo 3 do Regulamento n.º 51 da ONU, se optar pela comparação direta do sistema de escape de substituição com o sistema original, é permitido mudar a relação de transmissão para obter acelerações mais elevadas e a utilização de dispositivos eletrónicos ou mecânicos para impedir esta desaceleração não é obrigatória. Se, nestas condições, o nível de ruído do veículo de ensaio ultrapassar os valores da conformidade da produção (COP), o serviço técnico pronunciar-se-á sobre a representatividade do veículo de ensaio. <br> b) Medição com o veículo imobilizado Ao montar o sistema silencioso de escape de substituição ou os seus componentes no veículo mencionado no ponto 3.3.3, os níveis sonoros obtidos devem satisfazer uma das seguintes condições: i) O ou os valores medidos (arredondados para o número inteiro mais próximo) não devem ultrapassar em mais de 2 dB(A) o valor de homologação obtido ao abrigo do Regulamento n.º 51 da ONU com o modelo de veículo em questão; ii) O ou os valores medidos (antes de qualquer de arredondamento ao número inteiro mais próximo) não devem ultrapassar em mais de 2 dB(A) o valor do ruído medido (antes de qualquer arredondamento ao número inteiro mais próximo) no veículo referido no ponto 3.3.3, se este estiver equipado com um sistema silencioso de escape do tipo que estava montado no veículo aquando da sua apresentação para homologação nos termos do Regulamento n.º 51 da ONU. |
|---|---|---|

|  | 6.2.3. | Disposições adicionais em matéria de emissões sonoras (ASEP) |
|---|---|---|

|  | 6.2.3.1. | Os requisitos ASEP do ponto 6.2.3 do Regulamento n.º 51 da ONU devem também ser cumpridos no caso de um NORESS, se for concebido para equipar veículos homologados em conformidade com uma série de alterações ao Regulamento n.º 51 da ONU e se os requisitos ASEP faziam parte da homologação emitida para o veículo. <br> Se as disposições ASEP tiverem de ser verificadas, os ensaios correspondentes e os pré-ensaios necessários têm de ser realizados em conformidade com a série de alterações ao Regulamento n.º 51 da ONU, que serviu de base à homologação emitida para o veículo. |
|---|---|---|

|  | 6.2.3.2. | Se o NORESS tiver modos de funcionamento múltiplos, moduladores sonoros ou geometrias variáveis, deve também realizar os ensaios ASEP previstos no ponto 6.2.3 do Regulamento n.º 51 da ONU, se for concebido para equipar veículos homologados em conformidade com uma série de alterações ao Regulamento n.º 51 da ONU, e se os requisitos ASEP não faziam parte da homologação emitida para esses veículos. <br> Estes ensaios ASEP e os pré-ensaios necessários têm de ser realizados em conformidade com a série de alterações ao Regulamento n.º 51 da ONU que serviu de base à homologação emitida para esses veículos. <br> As emissões sonoras do veículo equipado com NORESS, em condições normais de condução, que são distintas das do ensaio de homologação previsto no anexo 3 e no anexo 7 do Regulamento n.º 51 da ONU, não se devem desviar do resultado do ensaio de uma forma significativa. |
|---|---|---|

|  | 6.2.3.3. | Os ensaios ASEP relativos ao ponto 6.2.3.2 têm de ser realizados em comparação com um veículo equipado com o silencioso de escape de origem e com um veículo equipado com o NORESS (ensaios consecutivos). Os ensaios ASEP do veículo equipado com o silencioso de escape de origem têm de ser efetuados nas condições normais de circulação, nomeadamente as que serviram de base à homologação do veículo no que diz respeito às emissões sonoras. Os resultados deste ensaio destinam-se apenas a servir de base de comparação em relação aos resultados dos ensaios ASEP do veículo equipado com NORESS. <br> Durante estes ensaios, o nível de pressão sonora do NORESS para cada condição de ensaio pode ter, no máximo, o mesmo nível de pressão sonora que o medido no veículo equipado com o silencioso de escape de origem quando o mesmo foi homologado. |
|---|---|---|

|  | 6.2.3.4. | Se os ensaios relativos aos pontos 6.2.3.1 ou 6.2.3.2 tiverem de ser realizados para um NORESS sem modos de funcionamento múltiplos, de regulação manual ou eletrónica, selecionáveis pelo condutor, sem moduladores sonoros, ou sem geometrias variáveis, deve utilizar-se um veículo conforme ao descrito no ponto 3.3.3. |
|---|---|---|

|  | 6.2.3.5. | Se os ensaios ASEP relativos aos pontos 6.2.3.1 ou 6.2.3.2 tiverem de ser realizados para um NORESS, equipado com modos de funcionamento múltiplos, de regulação manual ou eletrónica, selecionáveis pelo condutor, sem moduladores sonoros, ou com geometrias variáveis, cada modelo de veículo da gama de aplicação da homologação do NORESS tem de ser ensaiado em cada modo selecionável do veículo e do NORESS. |
|---|---|---|

|  | 6.2.3.6. | Os ensaios ASEP relativos ao ponto 6.2.3.4. podem ser realizados pelo fabricante do NORESS. <br> Os ensaios ASEP relativos ao ponto 6.2.3.5 têm de ser realizados pelo serviço técnico competente. Os resultados das medições do veículo de origem e do veículo equipado com NORESS, bem como todos os dados pertinentes desses ensaios, têm de ser mencionados no relatório de ensaio do referido serviço técnico. |
|---|---|---|

|  | 6.2.3.7. | A entidade homologadora pode exigir qualquer ensaio pertinente a fim de verificar a conformidade do NORESS com os requisitos dos pontos 6.2.3.1 a 6.2.3.6. Durante estes ensaios, a entidade homologadora pode também verificar o software das unidades de comando do NORESS, que estão equipados com modos de funcionamento múltiplos, de regulação eletrónica, selecionáveis pelo condutor, com moduladores sonoros ou com geometrias variáveis. |
|---|---|---|

|  | 6.2.3.8. | Além do relatório de ensaio do serviço técnico, o fabricante deve fornecer uma declaração em conformidade com o apêndice do anexo 7 do Regulamento n.º 51 da ONU, indicando que o tipo de sistema silencioso de escape a homologar cumpre os requisitos do ponto 6.2.3 do presente regulamento. |
|---|---|---|

|  | 6.2.3.9. | No caso dos NORESS equipados com modos de funcionamento múltiplos, de regulação manual ou eletrónica, selecionáveis pelo condutor, com moduladores sonoros ou com geometrias variáveis, o fabricante do NORESS tem de enviar à entidade homologadora um dossiê adicional que pormenorize o(s) princípio(s) de funcionamento e o modo de controlo do NORESS em conformidade com o ponto 6.2.4. |
|---|---|---|

|  | 6.2.4. | Documentação adicional para NORESS equipados com modos de funcionamento múltiplos, de regulação manual ou eletrónica, selecionáveis pelo condutor, com moduladores sonoros ou com geometrias variáveis |
|---|---|---|

|  | 6.2.4.1. | O dossiê adicional exigido pelo ponto 6.2.3.9 permite à entidade homologadora avaliar a estratégia ou estratégias de controlo das emissões sonoras para assegurar o funcionamento correto do NORESS. <br> Deve ser disponibilizado nas duas partes seguintes: <br> a) O «dossiê adicional formal», que pode ser facultado às partes interessadas mediante pedido; <br> b) O «dossiê adicional alargado», que deve permanecer estritamente confidencial. |
|---|---|---|

|  | 6.2.4.2. | O dossiê adicional formal pode ser sucinto, desde que apresente provas de que foram identificados todos os parâmetros para controlar o NORESS. A documentação adicional deve descrever o funcionamento do NORESS. Esta documentação deve ser conservada pela entidade homologadora. |
|---|---|---|

|  | 6.2.4.3. | O dossiê adicional alargado deve incluir informações sobre o funcionamento de todas as estratégias adicionais em matéria de emissões sonoras e da estratégia de base em matéria de emissões sonoras, incluindo uma descrição dos parâmetros alterados por qualquer estratégia adicional e as condições-limite em que uma tal estratégia funciona, bem como a indicação das estratégias adicionais ou de base que são suscetíveis de ser ativadas nas condições dos procedimentos de ensaio estabelecidos no requisito ASEP aplicável do Regulamento n.º 51 da ONU. O dossiê alargado deve incluir todos os modos de funcionamento. <br> O dossiê alargado deve permanecer estritamente confidencial. Esta documentação deve ser conservada pela entidade homologadora. |
|---|---|---|

|  | 6.3. | Medição do desempenho do veículo |
|---|---|---|

|  | 6.3.1. | O sistema silencioso de escape de substituição ou os seus componentes devem assegurar um desempenho do veículo comparável ao obtido com um sistema silencioso de escape ou um seu componente de origem. |
|---|---|---|

|  | 6.3.2. | O sistema silencioso de escape de substituição ou, segundo a escolha do fabricante, os componentes deste sistema, são comparados com um sistema silencioso de escape de origem ou componentes de um sistema silencioso de escape de origem, igualmente novos, sucessivamente montados no veículo referido no ponto 3.3.3 anterior. |
|---|---|---|

|  | 6.3.3. | A verificação deve ser realizada mediante medição da contrapressão segundo o disposto no ponto 6.3.4 seguinte. <br> O valor medido com o sistema silencioso de escape de substituição não deve ultrapassar em mais de 25 % o valor medido com o sistema silencioso de escape de origem, nas condições a seguir enunciadas. |
|---|---|---|

|  | 6.3.4. | Método de ensaio |
|---|---|---|

|  | 6.3.4.1. | Método de ensaio com motor <br> Efetuam-se as medições no motor referido no ponto 3.3.4 anterior montado num banco dinamométrico. Com o comando da aceleração completamente aberto, o banco deve ser regulado de modo a obter a velocidade nominal do motor (S) correspondente à potência útil nominal máxima do motor. <br> Para medir a contrapressão, a distância à qual a tomada de pressão deve ser colocada relativamente ao coletor de escape está indicada no anexo 4 do presente regulamento. |
|---|---|---|

|  | 6.3.4.2. | Método de ensaio com veículo <br> As medições devem ser efetuadas no veículo referido no ponto 3.3.3 anterior. O ensaio deve ser realizado em circulação na via pública ou num banco de rolos. <br> Com o comando da aceleração completamente aberto, o motor deve ser carregado de modo a obter a velocidade nominal do motor (S) correspondente à potência útil nominal máxima do motor. <br> Para medir a contrapressão, a distância à qual a tomada de pressão deve ser colocada relativamente ao coletor de escape está indicada no anexo 4 do presente regulamento. |
|---|---|---|

|  | 6.4. | Especificações adicionais relativas aos sistemas silenciosos de substituição ou seus componentes que contenham materiais fibrosos insonorizantes |
|---|---|---|

|  | 6.4.1. | Generalidades <br> Podem ser utilizados materiais fibrosos insonorizantes nos sistemas silenciosos de escape ou seus componentes se for preenchida qualquer uma das seguintes condições: <br> a) Os gases de escape não estão em contacto com os materiais fibrosos; ou se <br> b) O sistema silencioso de escape ou os seus componentes pertencem à mesma família que os sistemas ou componentes que, no decurso do processo de homologação em conformidade com os requisitos do presente regulamento, demonstraram não estar sujeitos a deterioração. <br> A menos que uma destas condições se encontre preenchida, o sistema silencioso de escape completo ou os seus componentes devem ser sujeitos ao condicionamento convencional mediante uma das três instalações e procedimentos descritos a seguir. <br> Para efeitos da alínea b) anterior, considera-se que vários sistemas silenciosos de escape ou componentes de sistema silencioso de escape pertencem à mesma família quando partilham todas as seguintes características: <br> a) O balanço de caudal dos gases de escape que atravessa os materiais fibrosos insonorizantes ao entrar em contacto com esses materiais; <br> b) O tipo de fibras; <br> c) Se for caso disso, a natureza do aglutinante; <br> d) As dimensões médias das fibras; <br> e) A densidade de embalagem mínima das fibras a granel em kg/m^3; <br> f) A superfície de contacto máxima entre o caudal gasoso e os materiais insonorizantes. |
|---|---|---|

|  | 6.4.1.1. | Percurso contínuo de 10 000 km em estrada |
|---|---|---|

|  | 6.4.1.1.1. | Este percurso deve incluir 50 ± 20 % de condução urbana e o restante de percursos longos a alta velocidade; o percurso contínuo na via pública pode ser substituído por um programa correspondente numa pista de ensaio. <br> Os dois regimes de velocidade devem ser alternados pelo menos duas vezes. <br> O programa de ensaio completo deve compreender, no mínimo, dez interrupções de, pelo menos, três horas, a fim de reproduzir os efeitos do arrefecimento e de eventuais condensações. |
|---|---|---|

|  | 6.4.1.2. | Condicionamento em banco de ensaio |
|---|---|---|

|  | 6.4.1.2.1. | Tendo o cuidado de utilizar peças normalizadas e de respeitar as instruções do fabricante, deve ser montado o sistema de silencioso de escape, ou os componentes desse sistema, no veículo mencionado no ponto 3.3.3 do presente regulamento ou no motor referido no ponto 3.3.4 do mesmo regulamento. No primeiro caso, o veículo deve ser colocado sobre um banco de rolos. No segundo caso, o motor é montado num banco dinamométrico. |
|---|---|---|

|  | 6.4.1.2.2. | Os ensaios devem ser efetuados em seis períodos de seis horas, com uma interrupção de, pelo menos, 12 horas entre cada período, para reproduzir os efeitos do arrefecimento e de eventuais condensações. |
|---|---|---|

|  | 6.4.1.2.3. | Durante cada período de seis horas, far-se-á funcionar o motor sucessivamente nas seguintes condições: <br> a) Sequência de 5 minutos em marcha lenta sem carga; <br> b) Sequência de 1 hora a ¼ carga e a ¾ da velocidade máxima nominal (S); <br> c) Sequência de 1 hora a meia carga e a ¾ da velocidade máxima nominal (S); <br> d) Sequência de 10 minutos a plena carga e a ¾ da velocidade máxima nominal (S); <br> e) Sequência de 15 minutos a meia carga e à velocidade máxima nominal (S); <br> f) Sequência de 30 minutos a ¼ da carga e à velocidade máxima nominal (S). <br> Cada período deve compreender duas séries de sequências das seis condições anteriormente mencionadas na ordem indicada de a) a f). |
|---|---|---|

|  | 6.4.1.2.4. | Durante o ensaio, não se procederá a nenhum arrefecimento do sistema silencioso de escape ou dos seus componentes por circulação de ar simulando a passagem de ar em redor do veículo. <br> No entanto, a pedido do fabricante, o sistema silencioso de escape ou os seus componentes podem ser arrefecidos de modo a não exceder a temperatura registada no seu ponto de entrada quando o veículo circula à velocidade máxima. |
|---|---|---|

|  | 6.4.1.3. | Condicionamento por pulsações |
|---|---|---|

|  | 6.4.1.3.1. | O sistema de silencioso de escape ou os seus componentes devem ser montados no veículo mencionado no ponto 3.3.3 do presente regulamento ou no motor mencionado no ponto 3.3.4 do mesmo regulamento. No primeiro caso, o veículo deve ser colocado num banco de rolos e, no segundo caso, o motor deve ser montado num banco dinamométrico. |
|---|---|---|

|  | 6.4.1.3.2. | A aparelhagem de ensaio, cujo esquema detalhado é ilustrado pela figura 3 do Apêndice ao Anexo 5 do Regulamento n.º 51 da ONU, deve ser montada à saída do sistema silencioso de escape. Aceita-se qualquer outra aparelhagem que dê resultados equivalentes. |
|---|---|---|

|  | 6.4.1.3.3. | A aparelhagem de ensaio deve ser regulada de tal forma que o fluxo dos gases de escape seja alternativamente interrompido e restabelecido pela válvula de corte rápido durante 2 500 ciclos. |
|---|---|---|

|  | 6.4.1.3.4. | A válvula deve abrir-se quando a contrapressão dos gases de escape, medida pelo menos 100 mm a jusante da flange de entrada, atingir um valor compreendido entre 35 e 40 kPa. Deve fechar-se assim que esta pressão não difira mais do que 10 % do valor estabilizado medido com a válvula aberta. |
|---|---|---|

|  | 6.4.1.3.5. | O relé temporizado deve estar regulado para a duração de evacuação dos gases que resulte das prescrições do ponto 6.4.1.3.4 anterior. |
|---|---|---|

|  | 6.4.1.3.6. | A velocidade do motor deve ser igual a 75 % da velocidade (S) a que o motor desenvolve a sua potência útil nominal máxima. |
|---|---|---|

|  | 6.4.1.3.7. | A potência indicada pelo dinamómetro deve corresponder a 50 % da potência útil nominal máxima desenvolvida com a aceleração máxima medida a 75 % da velocidade de rotação nominal do motor (S). |
|---|---|---|

|  | 6.4.1.3.8. | Todos os orifícios de drenagem devem estar obturados durante o ensaio. |
|---|---|---|

|  | 6.4.1.3.9. | O ensaio deve ser completado em 48 horas. Se for necessário, pode-se cumprir um período de arrefecimento após cada período de uma hora. |
|---|---|---|

|  | 6.4.1.3.10. | Após o condicionamento, deve-se verificar o nível de ruído em conformidade com o ponto 6.2 anterior. |

#### 7. Extensão da homologação

O fabricante do sistema silencioso de escape ou o seu representante devidamente acreditado pode solicitar à entidade homologadora que concedeu a homologação do sistema silencioso de escape para um ou mais modelos de veículo uma extensão da homologação a outros modelos de veículo.

O procedimento é descrito no ponto 3 anterior. A extensão da homologação (ou a recusa da mesma) deve ser comunicada às partes no Acordo que apliquem o presente regulamento através do procedimento descrito no ponto 5.3 anterior.

#### 8. Modificação do tipo de sistema silencioso de escape

|  | 8.1. | Qualquer alteração do tipo de sistema silencioso de escape de substituição deve ser notificada à entidade homologadora que o homologou. Essa entidade pode então: |
|---|---|---|

|  | 8.1.1. | considerar que as modificações introduzidas não são suscetíveis de ter efeitos adversos apreciáveis; ou |
|---|---|---|

|  | 8.1.2. | exigir um novo relatório de ensaio ao serviço técnico responsável pela realização dos ensaios. |
|---|---|---|

|  | 8.2. | A confirmação ou a recusa de homologação, com especificação das alterações ocorridas, deve ser comunicada, através do procedimento previsto no ponto 5.3, às partes no Acordo que apliquem o presente regulamento. |
|---|---|---|

#### 9. Conformidade da produção

Os procedimentos relativos ao controlo da conformidade da produção devem cumprir o disposto no apêndice 1 do Acordo (E/ECE/TRANS/505/Rev.1), bem como os seguintes requisitos:

|  | 9.1. | Os sistemas silenciosos de escape de substituição que ostentem uma marca de homologação em conformidade com as prescrições do presente regulamento devem ser conformes ao tipo de sistema silencioso de escape homologado e cumprir o disposto no ponto 6 anterior. Para efeitos de conformidade da produção, aplicam-se os valores-limite estabelecidos no ponto 6 com uma margem adicional de 1 dB(A). |
|---|---|---|

|  | 9.2. | Para verificar a conformidade prevista no ponto 9.1 anterior, devem ser efetuados controlos de produção adequados. |
|---|---|---|

|  | 9.3. | O titular da homologação deve em especial: |
|---|---|---|

|  | 9.3.1. | Assegurar a existência de procedimentos para um controlo efetivo da qualidade dos produtos; |
|---|---|---|

|  | 9.3.2. | Ter acesso ao equipamento de controlo necessário para verificar a conformidade de cada tipo homologado; |
|---|---|---|

|  | 9.3.3. | Assegurar que os dados dos resultados dos ensaios sejam registados e que os documentos anexos fiquem disponíveis durante um período a determinar com o acordo da entidade homologadora; |
|---|---|---|

|  | 9.3.4. | Analisar os resultados de cada tipo de produto para verificar e assegurar a estabilidade das características do produto, admitindo as variações próprias de uma produção industrial; |
|---|---|---|

|  | 9.3.5. | Assegurar que sejam efetuados, para cada tipo de produto, pelo menos os ensaios prescritos no anexo 5, ponto 2; |
|---|---|---|

|  | 9.3.6. | Assegurar que cada amostra ou provete que evidencie não conformidade com o tipo de ensaio previsto dê origem à colheita de uma nova amostra e a um novo ensaio. Devem ser tomadas todas as medidas necessárias para restabelecer a conformidade da produção correspondente. |
|---|---|---|

|  | 9.4. | A entidade homologadora que concedeu a homologação pode verificar em qualquer altura o método de controlo da conformidade aplicável a cada unidade da produção. |
|---|---|---|

|  | 9.4.1. | Em cada inspeção, os cadernos dos ensaios e os registos da fiscalização da produção devem ser apresentados ao inspetor. |
|---|---|---|

|  | 9.4.2. | O inspetor pode selecionar amostras ao acaso, que serão ensaiadas no laboratório do fabricante. O número mínimo de amostras pode ser determinado em conformidade com os resultados da própria verificação do fabricante; |
|---|---|---|

|  | 9.4.3. | Se o nível de qualidade se afigurar insatisfatório ou se parecer ser necessário verificar a validade dos ensaios efetuados em aplicação do ponto 9.4.2 anterior, o inspetor pode selecionar amostras a serem enviadas ao serviço técnico que realizou os ensaios de homologação. |
|---|---|---|

|  | 9.4.4. | A entidade homologadora pode realizar qualquer ensaio previsto no presente regulamento. |
|---|---|---|

|  | 9.4.5. | A frequência normal das inspeções pela entidade homologadora é bienal. Se forem registados resultados insatisfatórios durante uma dessas inspeções, a entidade homologadora deve assegurar que são tomadas todas as medidas necessárias para restabelecer a conformidade da produção tão rapidamente quanto possível. |

#### 10. Informações destinadas aos utilizadores e à inspeção técnica

Cada sistema silencioso de substituição deve ser acompanhado de um documento em papel emitido pelo respetivo fabricante ou pelo seu representante. Esse documento em papel deve incluir, pelo menos, as informações previstas no anexo 6 do presente regulamento.

#### 11. Sanções por não conformidade da produção

|  | 11.1. | A homologação concedida a um tipo de sistema silencioso de escape nos termos do presente regulamento pode ser revogada se o disposto no ponto 9 anterior não for cumprido ou se o sistema silencioso de escape ou os seus componentes não forem aprovados nos controlos referido no ponto 9.2 anterior. |
|---|---|---|

|  | 11.2. | Se uma parte no Acordo que aplique o presente regulamento revogar uma homologação que havia previamente concedido, deve notificar imediatamente desse facto as restantes partes contratantes que apliquem o presente regulamento, utilizando uma cópia do certificado de homologação, da qual conste no final, em maiúsculas, a anotação, assinada e datada: «homologação revogada». |
|---|---|---|

#### 12. Cessação definitiva da produção

Se o titular da homologação deixar definitivamente de fabricar um tipo de sistema silencioso de substituição ou seus componentes nos termos do presente regulamento, deve informar desse facto a entidade homologadora. Após receber a comunicação em causa, essa entidade deve do facto informar as outras partes no Acordo que apliquem o presente regulamento, utilizando uma cópia do certificado de homologação, da qual conste no final, em maiúsculas, a anotação, assinada e datada: «cessação da produção».

#### 13. Designações e endereços dos serviços técnicos responsáveis pela realização dos ensaios de homologação e das entidades homologadoras

As partes contratantes no Acordo de 1958 que apliquem o presente regulamento devem comunicar ao Secretariado das Nações Unidas as designações e os endereços dos serviços técnicos responsáveis pela realização dos ensaios de homologação e das entidades homologadoras que concedem essas homologações e aos quais devem ser enviados os certificados de concessão, extensão, recusa ou revogação da homologação emitidos noutros países.

#### 14. Disposições transitórias

|  | 14.1. | A contar da data oficial da entrada em vigor da série 03 de alterações ao presente regulamento, nenhuma parte contratante que aplique o presente regulamento pode recusar a concessão ou a aceitação de homologações nos termos da série 03 de alterações ao presente regulamento. |
|---|---|---|

|  | 14.2. | A partir de 12 meses após a data de entrada em vigor, as partes contratantes que apliquem o presente regulamento apenas devem conceder homologações se o tipo de componente ou unidade técnica a homologar cumprirem os requisitos constantes da série 03 de alterações do presente regulamento. |
|---|---|---|

|  | 14.3. | A partir de 24 meses após a data de entrada em vigor, as partes contratantes que apliquem o presente regulamento apenas devem conceder extensões a homologações existentes se o tipo de componente ou unidade técnica a homologar cumprirem os requisitos constantes da série 03 de alterações ao presente regulamento. |
|---|---|---|

|  | 14.4. | Mesmo após a entrada em vigor da série 03 de alterações ao presente regulamento, as homologações de componentes e unidades técnicas conformes à série precedente de alterações ao presente regulamento da ONU continuam a ser válidas, e as partes contratantes que apliquem o presente regulamento devem continuar a aceitá-las como tal. |

## ANEXO 5

#### Controlo de conformidade da produção

#### 1. Generalidades

As presentes prescrições são compatíveis com os ensaios a efetuar para verificar a conformidade da produção (COP), em conformidade com os pontos 9.3.5 e 9.4.3 do presente regulamento.

#### 2. Ensaios e procedimentos

Os métodos de ensaio, instrumentos de medição e interpretação dos resultados devem ser os descritos no ponto 6 do presente regulamento. O sistema de escape ou o componente de silencioso de escape a ensaiar é submetido ao ensaio descrito nos pontos 6.2, 6.3 e 6.4 do presente regulamento.

#### 3. Amostragem e avaliação dos resultados

É necessário selecionar um sistema silencioso de escape ou um componente de silencioso de escape e submetê-lo aos ensaios do ponto 2 anterior. Se os resultados de ensaio cumprirem os requisitos de conformidade da produção do ponto 9.1 do presente regulamento, considera-se que o tipo de sistema silencioso de escape ou de componente de silencioso de escape cumpre as referidas prescrições.

Se um dos resultados de ensaio não cumprir os requisitos de conformidade da produção do ponto 9.1 do presente regulamento, devem ser ensaiados outros dois sistemas silenciosos de escape ou componentes de silencioso de escape do mesmo tipo, em conformidade com o ponto 2 anterior.

Se os resultados de ensaio do segundo e do terceiro sistemas silenciosos de escape ou componentes cumprirem os requisitos de conformidade da produção do ponto 9.1 do presente regulamento, considera-se que o tipo de sistema silencioso de escape ou de componente de silencioso de escape cumpre as referidas prescrições.

Se um dos resultados de ensaio do segundo ou do terceiro sistemas silenciosos de escape ou componente de silencioso de escape não cumprir os requisitos de conformidade da produção do ponto 9.1 do presente regulamento, considera-se que o tipo de sistema silencioso de escape ou de componente de silencioso de escape não é conforme com os requisitos do presente regulamento, devendo o fabricante tomar as medidas necessárias para restabelecer a conformidade.
