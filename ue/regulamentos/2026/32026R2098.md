# Regulamento de Execução (UE) 2026/2098 da Comissão, de 18 de setembro de 2026, que estabelece os elementos de metadados mínimos e as suas características a facultar pelos detentores dos dados de saúde no que se refere às descrições dos conjuntos de dados para a utilização secundária de dados de saúde eletrónicos nos termos do artigo 77.º, n.º 4, do Regulamento (UE) 2025/327 que cria o Espaço Europeu de Dados de Saúde

**Ainda não está em vigor:** entrada em vigor prevista a 2026-10-11.

**Texto:** versão original publicada no Jornal Oficial (sem alterações posteriores, se as houver).

## Preâmbulo

A COMISSÃO EUROPEIA,

Tendo em conta o Tratado sobre o Funcionamento da União Europeia,

Tendo em conta o Regulamento (UE) 2025/327 do Parlamento Europeu e do Conselho, de 11 de fevereiro de 2025, relativo ao Espaço Europeu de Dados de Saúde e que altera a Diretiva 2011/24/UE e o Regulamento (UE) 2024/2847 [^1], nomeadamente o artigo 77.º, n.º 4, primeira frase,

Considerando o seguinte:

- (1) O artigo 77.º, n.º 1, do Regulamento (UE) 2025/327 exige que os organismos responsáveis pelo acesso aos dados de saúde disponibilizem ao público catálogos de conjuntos de dados com uma descrição, sob a forma de metadados, dos conjuntos de dados disponíveis para a utilização secundária de dados de saúde eletrónicos, incluindo informações sobre a fonte, o âmbito, as principais características e a natureza dos dados de saúde eletrónicos nos conjuntos de dados e as condições de disponibilização desses dados.

- (2) Para o efeito, e em conformidade com o artigo 60.º, n.º 3, do Regulamento (UE) 2025/327, cabe aos detentores dos dados de saúde comunicar aos organismos responsáveis pelo acesso aos dados de saúde essa descrição referente ao conjunto de dados que detêm, independentemente de os conjuntos de dados conterem dados de saúde eletrónicos pessoais e/ou não pessoais.

- (3) Em conformidade com o artigo 60.º, n.º 3, do Regulamento (UE) 2025/327, os detentores dos dados de saúde são obrigados a verificar, no mínimo, anualmente, se as descrições dos conjuntos de dados são exatas e estão atualizadas. Esta verificação é essencial para assegurar a fiabilidade e a usabilidade dos catálogos de conjuntos de dados para a utilização secundária de dados de saúde eletrónicos.

- (4) Conforme previsto no artigo 77.º, n.º 1, do Regulamento (UE) 2025/327, os catálogos de conjuntos de dados devem ser normalizados e legíveis por máquina, a fim de assegurar a interoperabilidade semântica e técnica entre todos os Estados-Membros. Esta interoperabilidade é necessária para permitir a interligação dos catálogos nacionais de conjuntos de dados e dos catálogos de conjuntos de dados de participantes autorizados com o catálogo da UE de conjuntos de dados estabelecido nos termos do artigo 79.º do referido regulamento. Por conseguinte, importa que os detentores dos dados de saúde, ao facultarem os elementos de metadados mínimos e as características desses elementos, adotem uma abordagem comum no que se refere aos metadados para as descrições dos conjuntos de dados.

- (5) É conveniente que seja utilizado como um tal quadro de metadados o perfil de aplicação HealthDCAT (HealthDCAT-AP). O HealthDCAT-AP baseia-se no perfil de aplicação DCAT geral e consiste numa especificação técnica criada e mantida pela Comissão, concebida especificamente para apoiar a descrição dos conjuntos de dados de saúde disponibilizados para a utilização secundária de dados de saúde eletrónicos. Essas especificações são fornecidas em conformidade com as decisões operacionais dos organismos pertinentes criados nos termos dos artigos 92.º e 95.°, no âmbito do regime de governação do Espaço Europeu de Dados de Saúde.

- (6) O presente regulamento contribui para a interoperabilidade das infraestruturas digitais de apoio ao Espaço Europeu de Dados de Saúde, incluindo as que estão associadas ao acesso transfronteiras aos dados. Foi realizada uma avaliação da interoperabilidade, cujo relatório será publicado no portal Europa Interoperável aquando da adoção do presente regulamento.

- (7) As medidas previstas no presente regulamento estão em conformidade com o parecer do comité instituído pelo artigo 98.º, n.º 1, do Regulamento (UE) 2025/327,

ADOTOU O PRESENTE REGULAMENTO:

## Texto

### Artigo 1.º — Objeto e âmbito de aplicação

1. O presente regulamento estabelece os elementos de metadados mínimos no que se refere às descrições dos conjuntos de dados, bem como as características desses elementos, que os detentores dos dados de saúde são obrigados a facultar aos organismos responsáveis pelo acesso aos dados de saúde nos termos do artigo 60.º, n.º 3, do Regulamento (UE) 2025/327 para a utilização secundária de dados de saúde eletrónicos, bem como o quadro de metadados a utilizar para esse efeito.

2. O presente regulamento é igualmente aplicável, se for caso disso, aos participantes autorizados na infraestrutura «Dados de saúde @ UE» (HealthData@EU) quando facultam descrições dos conjuntos de dados nos termos do Regulamento (UE) 2025/327.

3. O presente regulamento não impede os detentores dos dados de saúde de facultarem elementos de metadados adicionais e as suas características a título voluntário, utilizando, para esse efeito, o quadro de metadados a que se refere o primeiro parágrafo.

### Artigo 2.º — Definições

Para efeitos do disposto no presente regulamento, são aplicáveis as definições que constam do perfil de aplicação HealthDCAT-AP a que se refere a parte A do anexo.

### Artigo 3.º — Requisitos relativos aos elementos de metadados mínimos

A lista dos elementos de metadados mínimos que os detentores dos dados de saúde devem facultar no que se refere às descrições dos conjuntos de dados, bem como as características desses elementos, constam da parte B do anexo.

Os detentores dos dados de saúde devem expressar os elementos de metadados mínimos enumerados na parte B do anexo utilizando as definições, a estrutura, as cardinalidades e os vocabulários controlados estabelecidos no perfil de aplicação HealthDCAT-AP, a que se referem as partes A e C do anexo.

### Artigo 4.º — Entrada em vigor

O presente regulamento entra em vigor no vigésimo dia seguinte ao da sua publicação no Jornal Oficial da União Europeia.

O presente regulamento é aplicável a partir de 26 de março de 2029.

O presente regulamento é obrigatório em todos os seus elementos e diretamente aplicável em todos os Estados-Membros.

Feito em Bruxelas, em 18 de setembro de 2026.

Pela Comissão

## ANEXO

#### PARTE A

#### Referência técnica

O quadro de metadados referido no artigo 1.º baseia-se no perfil de aplicação HealthDCAT-AP, que é mantido e disponibilizado ao público pela Comissão [^1].

#### PARTE B

#### Elementos de metadados

Os elementos a seguir enumerados devem ser expressos utilizando as especificações técnicas do perfil de aplicação HealthDCAT-AP, conforme indicadas na parte A do presente anexo. Quando aplicável, têm de ser utilizados vocabulários controlados definidos no perfil de aplicação HealthDCAT-AP.

| Propriedade | Descrição |
|---|---|
| Direitos de acesso | Descreve o nível de acesso aplicável ao conjunto de dados (por exemplo, público, restrito ou não público). |
| Legislação aplicável | Identifica os atos jurídicos da União ou a legislação nacional que regem especificamente o estabelecimento, a manutenção ou a disponibilidade do conjunto de dados, caso esses atos jurídicos ou legislação existam. |
| Representação codificada | Identifica sistemas de classificação ou vocabulários controlados refletidos no conteúdo do conjunto de dados (por exemplo, classificações de doenças, classificações de procedimentos), quando aplicável. |
| Sistema de codificação | Identifica os sistemas de codificação normalizados utilizados para codificar elementos de dados no conjunto de dados (por exemplo, CID-10-CM, SNOMED-CT, GDH), quando aplicável. |
| Ponto de contacto | Apresenta os dados de contacto para pedidos de informação relacionados com o conjunto de dados. |
| Em conformidade com | Identifica uma norma ou especificação técnica que define a organização estrutural ou sintática global do conjunto de dados. |
| Tutor | Identifica a organização responsável pela detenção, gestão e manutenção do conjunto de dados ao longo do tempo (detentor dos dados de saúde). |
| Descrição | Apresenta um resumo em texto livre que descreve o conteúdo e a finalidade do conjunto de dados. |
| Distribuição | Apresenta uma representação técnica ou um formato no qual o conjunto de dados é disponibilizado para utilização secundária. |
| Cobertura geográfica | Indica a área geográfica a que o conjunto de dados diz respeito (por exemplo, um Estado-Membro, uma região ou toda a UE), quando aplicável. |
| Contém dados pessoais | Indica se o conjunto de dados contém dados pessoais na aceção do artigo 4.º, ponto 1), do Regulamento (UE) 2016/679 do Parlamento Europeu e do Conselho[^2]. |
| Organismo responsável pelo acesso aos dados de saúde | O organismo competente responsável pelo acesso aos dados de saúde encarregado de facilitar o acesso ao conjunto de dados no âmbito do Espaço Europeu de Dados de Saúde, caso o conjunto de dados esteja sujeito a acesso restrito ou não público. |
| Categoria de dados de saúde | Identifica as categorias de dados de saúde eletrónicos contidas no conjunto de dados e enumeradas no artigo 51.º, n.º 1, do Regulamento (UE) 2025/327. |
| Tema de saúde | Indica um tema ou tópico de saúde abrangente associado ao conjunto de dados (por exemplo, doença cardiovascular, cancro). |
| Identificador | Apresenta um identificador único e persistente para o conjunto de dados [por exemplo, identificador uniforme de recurso (URI), identificador digital de objetos (DOI) ou identificador de catálogo]. |
| É estruturado | Indica se o conjunto de dados é estruturado, ou seja, se está organizado de acordo com um esquema ou modelo predefinido que defina as suas variáveis, atributos ou campos. |
| Palavra-chave | Apresenta palavras-chave ou etiquetas que descrevem o conjunto de dados e apoiam a pesquisa e a descoberta. |
| Língua | Indica a língua ou línguas em que o conteúdo do conjunto de dados é expresso. |
| Número de registos | Indica o número total de registos no conjunto de dados, quando aplicável. |
| Número de pessoas individuais | Indica um número estimado de pessoas singulares individuais representadas no conjunto de dados, sempre que o conjunto de dados contenha dados pessoais e quando for aplicável. |
| Proveniência | Descreve a origem, a fonte ou o processo de criação do conjunto de dados. |
| Editor | Indica a entidade que disponibiliza o conjunto de dados, que pode diferir do criador ou do tutor. |
| Cobertura temporal | Indica o período abrangido pelo conjunto de dados (por exemplo, os anos de recolha dos dados), caso existam informações temporais. |
| Título | Indica o nome ou título oficial do conjunto de dados. |
| Tipo | Indica a categoria geral ou a natureza do conjunto de dados (por exemplo, registo, conjunto de dados administrativos, conjunto de dados de investigação, conjunto de dados sintéticos). |
| Variáveis | Uma descrição estruturada das variáveis contidas no conjunto de dados, incluindo, se aplicável, o nome da variável, a definição, o tipo de dados, o sistema de codificação ou o domínio de valores. |
| Foi gerado por | Identifica a atividade ou o processo através do qual o conjunto de dados foi gerado (por exemplo, registo, estudo clínico, processo administrativo). |
| [^2]: Regulamento (UE) 2016/679 do Parlamento Europeu e do Conselho, de 27 de abril de 2016, relativo à proteção das pessoas singulares no que diz respeito ao tratamento de dados pessoais e à livre circulação desses dados e que revoga a Diretiva 95/46/CE (Regulamento Geral sobre a Proteção de Dados) (JO L 119 de 4.5.2016, p. 1, ELI: http://data.europa.eu/eli/reg/2016/679/oj). |  |

#### PARTE C

#### Vocabulários controlados

Ao facultarem as descrições dos conjuntos de dados, os detentores dos dados de saúde devem utilizar os vocabulários controlados a seguir enumerados:

| Propriedade dos metadados | Vocabulário controlado | Fonte |
|---|---|---|
| Categoria de dados de saúde | As categorias enumeradas no artigo 51.º, n.º 1, alíneas a) a q) do Regulamento (UE) 2025/327 | Artigo 51.º, n.º 1, do Regulamento (UE) 2025/327 |

Sempre que sejam exigidos vocabulários controlados para os elementos de metadados mínimos estabelecidos no presente regulamento, devem ser utilizados os definidos no perfil de aplicação HealthDCAT-AP, conforme referido na parte A do presente anexo.
